Taxman is an intelligent conversational agent engineered to streamline tax assessment, compliance, and filing for Nigerian citizens and small-to-medium enterprises. Orchestrated using n8n workflow automation and modern foundation models, the agent provides accessible, multi-channel assistance for taxpayers navigating complex statutory schedules.

The system natively supports multimodal interactions, accepting user queries via text, voice notes, photographed receipts or invoices, and structured tabular files such as PDF statements and CSV ledgers. Input documents are parsed, validated, and contextualized using automated extraction pipelines.

To ensure strict statutory fidelity, Taxman incorporates a retrieval-augmented generation (RAG) architecture indexed on the Nigeria Tax Act 2025 and relevant fiscal circulars. Every computational breakdown, exemption guidance, and filing recommendation is directly linked to statutory citations, preventing hallucinations in high-stakes financial calculations.
